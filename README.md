# Atendente IA + CRM

Atendente de inteligência artificial para WhatsApp com CRM integrado: responde quem chega,
qualifica, marca horário e mantém o funil atualizado sozinho. Roda no computador ou num servidor,
com o mesmo código.

A instalação e o uso são ensinados no curso.
